# Project Structure

```text
selam-kids/
|- src/          Frontend routes, components, styles, and TanStack Start code
|- public/       Static assets and uploaded files
|- backend/      Express API, MongoDB models, routes, API handler, and fallback data
|- api/          Minimal Vercel serverless route forwarders (required by Vercel)
|- node_modules/ Installed dependencies (generated by npm, not committed)
```
